# Mikado 600 Tail Hub for OMP Tail Mech
This tail hub fits the standard Logo 600 series and allows to fit the tail mech of the OMP M5/6 models.

The hub must be printed in MJF (nylon powder). It is not recommended to print this from FDM both for strength and precision reasons.

The tail pulley needs to be drilled to fit the 6mm diameter OMP tail shaft and two holes must be made on the flanges to fit the pin that secures the pulley on the shaft. Since this is closed hub the pin must be inserted after the hub is in place so the Mikado method of using the internal hexagon to hold the pin does not work.
